## The question

Moving a near-Earth asteroid somewhere useful — into a stable orbit near Earth, the Moon or Mars — costs propellant, measured as ΔV. The research question is how small that ΔV can be for a given asteroid, and which candidates are cheapest to move.

## Real data

The tool works from **orbital data in the NASA JPL Small-Body Database** for candidate near-Earth asteroids, rather than invented starting conditions — so results describe real objects and can be checked against a published reference.

## The tool

I built a **Python tool that models and plots asteroid trajectories** using celestial mechanics. It propagates each asteroid's orbit and searches for the transfer that reaches a **stable orbit** near the target body for the **lowest ΔV**.

Timing matters: the same impulse applied at different points in an orbit changes it by very different amounts, so the search covers where along the orbit the burn happens as well as how big it is.

## Ansys STK

I use **Ansys STK (Systems Tool Kit)** for **orbit propagation** and to find **transfer windows** — the points along an orbit where moving to the target body costs the least ΔV.

## Visualisation

The tool plots the trajectories and transfers so alternatives can be compared side by side. The interactive simulator on the [research page](/research/) is a browser version of the same Keplerian propagation.
